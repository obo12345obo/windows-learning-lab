مختبري — كود الموقع الكامل الجاهز للرفع
=======================================

المحتويات
---------
index.html       صفحة الترحيب بالشعار
lessons.html     بوابات الدروس
update.html      محاكي تحديث Windows
cleanup.html     صفحة تنظيف القرص
cleanup.js       منطق محاكي تنظيف القرص
lab.html         صفحة بقية التطبيقات والمراجعة
lab.js           منطق المحاكيات والتفاعل
curriculum.js    محتوى الدروس والأسئلة والخطوات
lesson-menu.js   تبويبات الدروس وعلامات الإكمال
base.css         التنسيق الأساسي
lab.css          تنسيق التطبيقات الإضافية
lesson-ux.js     المهمة الحالية وشريط التقدم والانتقال للدرس التالي
lesson-ux.css    تنسيق تحسينات سهولة الاستخدام
responsive.css   تنسيق الشاشات الصغيرة والتابلت والحواسيب

طريقة الرفع
-----------
1. فك ضغط الملف ZIP أولًا.
2. افتح مدير ملفات الاستضافة أو استخدم برنامج نقل الملفات الخاص بك.
3. ارفع جميع ملفات HTML وCSS وJS معًا إلى مجلد الموقع، مثل public_html.
   يمكنك أيضًا رفعها معًا إلى مجلد فرعي مثل public_html/lab.
4. يجب أن يكون index.html داخل المجلد الذي سيُفتح كرابط الموقع، وليس
   داخل مجلد إضافي غير مقصود.
5. افتح رابط الموقع. إذا استخدمت مجلد lab، افتح رابط ذلك المجلد.
6. جرّب التبويبات وأزرار المحاكاة. إذا ظهرت نسخة قديمة حدّث الصفحة مع
   تجاوز ذاكرة التخزين المؤقت في المتصفح.

مهم: ارفع جميع ملفات الموقع مع الحفاظ على أسمائها. لا ترفع index.html وحده.
يمكن رفع ZIP وفك ضغطه من مدير ملفات الاستضافة إذا كانت الاستضافة تدعم ذلك.

تشغيل محلي
----------
بعد فك الضغط، افتح index.html من المتصفح لتجربة الموقع.
لا تحتاج عملية بناء أو تثبيت حزم، ولا إلى PHP أو Node.js أو قاعدة بيانات.
الموقع يعمل بـ HTML + CSS + JavaScript في المتصفح.

الدروس
------
- تهيئة الفلاش وتغيير اسمه.
- تحديث Windows.
- تنظيف القرص Disk Cleanup.
- مقارنة التحديث والترقية.
- فحص القرص Check Disk.
- إلغاء تجزئة HDD وضبط جدول التحسين.
- تفعيل Storage Sense.
- إعادة التشغيل وسيناريو Task Manager.
- مراجعة الدرس: 7 أسئلة.

التعديل
-------
لتعديل محتوى الدروس الجديدة وأسئلتها، افتح curriculum.js ببرنامج تحرير نصوص.
لتعديل مظهر الدروس، افتح base.css وlab.css.
الدرسان الأولان يحتويان أيضًا على تنسيقات داخل ملفي HTML الخاصين بهما.
احتفظ بنسخة احتياطية قبل التعديل واستخدم ترميز UTF-8 للنصوص العربية.

ملاحظات التشغيل
---------------
كل العمليات محاكاة داخل المتصفح ولا تغيّر جهاز الطالب.
علامات إكمال الدروس تُحفظ في المتصفح نفسه عند إتاحة التخزين المحلي.
لا توجد حسابات طلاب أو قاعدة بيانات لدرجات الصف.
النسخة مستقلة عن استضافة ChatGPT ولا تتطلب تسجيل دخول إلى ChatGPT.
توجد وصلة مرجعية خارجية إلى Microsoft ضمن درس المقارنة، وهي ليست
مطلوبة لتشغيل المحاكيات.

التحقق
------
تم اختبار تسلسل المحاكيات والحسابات والأسئلة برمجيًا.
لم تتوفر معاينة فعلية في المتصفح خلال إنشاء هذه النسخة.

المظهر الزجاجي
--------------
glass.css: المظهر الزجاجي وألوان هوية المدرسة.
assets/school-logo.png: الشعار المستخدم في خلفية الموقع ورأس الصفحة.
عند الرفع، ارفع مجلد assets أيضًا مع ملفات الموقع.

تصميم المدرسة الجديد
academy.css: الهوية البصرية وتنسيق واجهة المدرسة.
academy.js: الواجهة الافتتاحية وملخص التقدم.
التصميم يستخدم ملفات محلية فقط، دون خطوط أو مكتبات خارجية.
تشغيل محلي عبر Node.js: node serve.cjs ثم http://localhost:8080
تمت معاينة الصفحات الثلاث بالمتصفح واختبار عرض 320 و1440 بكسل ومسار Start ثم Settings.


تسلسل التصفح الجديد
------------------
index.html → lessons.html → المختبر المختار.
journey.css وjourney.js: تصميم الترحيب والبوابات وتقدّم الطالب.
رابط تحديث Windows أصبح update.html؛ الصفحة الرئيسية مخصصة للترحيب.
التنقّل لا يفرض إكمال درس قبل فتح غيره. تابع رحلتك يفتح أول درس غير مكتمل.
