# مختبري | Mokhtabari

مختبر حاسوب تعليمي بالعربية لطلبة الرابع الإعدادي، بهوية مجموعة مدارس الأوائل الأهلية.

## رحلة الطالب

صفحة ترحيب بالشعار ← بوابات الدروس ← التطبيق العملي.

ثمانية تطبيقات عملية ومراجعة نهائية: تهيئة الفلاش، تحديث Windows، تنظيف القرص، التحديث والترقية، فحص الأقراص، إلغاء التجزئة والجدولة، Storage Sense، وإعادة التشغيل.

جميع العمليات محاكاة داخل المتصفح. علامة إنجاز الدرس محفوظة في المتصفح نفسه، ولا توجد حسابات طلاب أو قاعدة بيانات مركزية.

## تشغيل محلي

يتطلب السيرفر المحلي Node.js فقط، دون تثبيت حزم:

```sh
node serve.cjs
```

افتح http://localhost:8080 . ويمكن فتح index.html مباشرةً من المتصفح أيضًا.

## التحقق

```sh
node tests/lesson-routes.cjs
node scripts/prepare-pages.cjs
```

التحضير يتحقق من روابط الصفحات والملفات وصحة JavaScript، وينسخ ملفات الموقع المطلوبة فقط إلى `_site/`.

## النشر على GitHub Pages

1. أنشئ مستودعًا عامًا وارفع المصدر على الفرع `main`.
2. من المستودع، افتح **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. من **Actions** شغّل **Publish Mokhtabari to GitHub Pages**، أو ادفع تحديثًا على `main`.
4. بعد نجاح النشر يظهر الرابط في **Settings → Pages** وفي ملخّص عملية النشر.

الموقع يستخدم روابط نسبية ليعمل من نطاق github.io ومن مجلد المشروع. لا يحتاج إعداد دومين مدفوع أو ملف CNAME.

ملفات PDF والصور المؤقتة ولقطات المعاينة ليست ضمن ملفات النشر. يتولى GitHub Actions اختبار المسارات ثم نشر محتويات `_site/` فقط.
